# USART/CAN/TCP 上位机 发布版说明

## 运行方式

双击 `USART_CAN_上位机.exe` 即可运行。

本程序已经打包为单文件 exe，不需要另外安装 Python，也不需要安装 `pyserial` 或 `python-can`。

TCP 功能不需要额外驱动。Client 模式填写远端地址和端口；Server 模式填写本机监听地址和端口，并等待客户端接入。

## 硬件驱动要求

如果只使用串口功能，一般不需要额外驱动；USB 转串口设备可能需要安装对应芯片驱动，例如 CH340、CP210x、FT232 等。

如果使用 CAN 功能，需要提前安装对应 CAN 设备的 Windows 驱动。例如：

- PCAN-USB：安装 PEAK-System 官方 PCAN 驱动。
- SLCAN/串口 CAN：安装对应 USB 转串口驱动。
- Kvaser、Vector、IXXAT 等设备：安装各自官方驱动。

驱动安装完成后，打开程序，选择协议和接口，再点击“刷新”查看可用通道。

## 文件发送说明

- `.bin` 文件按原始字节发送。
- `.hex` 文件按 Intel HEX 格式解析后发送。
- 普通文本文件会优先按 HEX 字节解析。
- 串口发送且延时为 `0` 时，程序会自动使用大块快速发送。
- 如果设置了“每 N 字节延时 M us/ms/s”，程序会严格按设置分块发送，延时单位支持微秒、毫秒和秒。

## 日志颜色

- TX：发送数据。
- RX：接收数据。
- 红色：错误或失败信息。
- 黄色：停止或警告信息。
- 橙色：实际数据字节。
